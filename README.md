# Bike-Sales-Excel-Dashboard
Interactive Excel dashboard analyzing bike sales data
Bike Sales Analysis Dashboard 
________________________________________
Project Objective
The objective of this project is to analyse bike sales data using Excel and build an interactive dashboard to understand customer demographics, purchasing behaviour, and sales trends.
The dashboard is designed to help business users quickly filter data and gain insights using slicers and visualizations.
________________________________________
Dataset Information
•	Source: Simulated dataset (provided for analysis practice)
•	Number of Records: Multiple customer-level sales entries
•	Key Columns:
o	Customer Age
o	Gender
o	Marital Status
o	Income
o	Region
o	Commute Distance
o	Purchased Bike (Yes/No)
________________________________________
Tools & Features Used
•	Microsoft Excel
o	Pivot Tables
o	Pivot Charts
o	Slicers
o	Data Cleaning
o	Logical Functions
o	Sorting & Filtering
o	Dashboard Design & Formatting
________________________________________
Data Cleaning & Preparation
•	Removed duplicate records
•	Standardized categorical values (Yes/No, Gender, Region)
•	Ensured correct data types for income and age
•	Created derived fields where required
•	Validated data before analysis
________________________________________
Analysis Performed
•	Analyzed bike purchases by gender and age group
•	Studied income levels of customers who purchased bikes
•	Compared purchase behaviour across regions
•	Evaluated the impact of commute distance on bike purchases
•	Identified key customer segments more likely to purchase bikes
________________________________________
Dashboard Overview
The Excel dashboard includes:
•	Interactive slicers for:
o	Gender
o	Marital Status
o	Region
o	Commute Distance
•	Pivot charts showing:
o	Bike purchase trends
o	Customer demographics
o	Income comparison
•	Dynamic updates based on slicer selections
________________________________________
Key Insights
•	Middle-aged customers showed higher bike purchase rates
•	Higher income groups were more likely to purchase bikes
•	Shorter commute distances correlated with increased bike purchases
•	Purchase behaviour varied noticeably across regions
________________________________________
Business Recommendations
•	Target marketing campaigns toward high-income and mid-age customer segments
•	Focus promotions in regions with higher purchase rates
•	Customize offers for customers with shorter commute distances
•	Use the dashboard for ongoing sales and customer analysis
